Notable changes to node 57945 over time, newest first. Entries before
November 10, 2026 were carried over from the change log on kj7t.net.

- **2026-11-10** — Ended the scheduled weekday monitor link to node 55915
  (WA7ABU net), and stopped the automatic reconnect monitor that kept
  that link up.
- **2026-11-10** — Created this GitHub space to document node 57945.
- **2026-03-18** — Added an automatic reconnect monitor for node 55915,
  running as a system service.
- **2026-03-17** — Added scripts to connect to and disconnect from node 55915
  each weekday morning. Installed pandoc to turn the Markdown change log into
  a web page.
- **2025-09-02** — Updated the system and upgraded AllScan to version 0.96.
- **2025-04-22** — Upgraded HamshackDashboard and added it to the kj7t.net menu.
- **2025-02-02** — Upgraded the kernel and DAHDI, using a fix from the
  AllStarLink community forum.
- **2025-01-26** — Temporarily rolled back to an earlier kernel to fix garbled
  audio through AllStarLink.
- **2025-01-11** — Took a fresh snapshot of the working system and installed
  updates.
- **2025-01-04** — Backed up the configuration, then installed updates.
- **2024-12-28** — Upgraded the node from AllStarLink 2 to AllStarLink 3, on
  Debian 12. The old tomhub.us domain now redirects to kj7t.net.
