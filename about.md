**Node:** 57945\
**Name:** KJ7T Pacific Northwest USA\
**Callsign:** KJ7T\
**Type:** Hub — radio-free, hosted on a cloud server

Node 57945 is an AllStarLink hub that runs on a cloud server rather than at
my home. Because it doesn't depend on my house's power or internet
connection, it stays up through local outages. Anyone is welcome to connect
to it from their own AllStarLink node.

## Live status and dashboard

The node's portal at [kj7t.net](https://kj7t.net) shows its current status
and links to its dashboard. If kj7t.net is unreachable, this page is the
fallback reference.
